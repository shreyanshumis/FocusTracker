# App logo

`logo.png` is a recreation of the user's attached blue/cyan/navy eye logo.
The original source file was unavailable. Generated with the built-in imagegen
tool on 2026-10-12; packaging resizes it into Windows and browser icons.

Prompt: “Use case: logo-brand. Attached image is the edit target: preserve this exact stylized navy eye emblem with cyan-to-royal-blue gradients, central blue iris and white highlight, and the same internal white negative-space letter forms. Prepare a clean square Windows app logo asset on solid white with the eye centered and occupying about 90% of the width. No added text, no extra symbols. Faithfully reproduce the supplied design; clean crisp edges, no texture. Save image to file for app packaging.”

Replace `logo.png` with the original if it becomes available and run
`python build_app.py` to regenerate all icons. Brand artwork is excluded from
the repository's MIT code license.
